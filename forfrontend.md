## 2. Как теперь запускать

### Первый раз (установка)

Нужны Python 3.11+ и Node.js 18+. Из корня репозитория:

```powershell
python -m venv .venv
.venv\Scripts\activate              # Mac/Linux: source .venv/bin/activate
pip install -r requirements.txt
npm install --legacy-peer-deps      # про флаг — см. раздел 4
```

### Каждый раз (запуск)

```powershell
.venv\Scripts\activate
python run.py
```

Скрипт сам применит миграции БД, поднимет бэкенд (порт 8000) и фронтенд (порт 5173). `Ctrl+C` останавливает оба.

| Адрес | Что это |
|---|---|
| **http://localhost:5173** | сайт — открывать его |
| http://127.0.0.1:8000/docs | Swagger бэкенда: все эндпоинты, можно потыкать |

По-старому, в двух терминалах, тоже работает: `uvicorn app.main:app --reload` и `npm run dev`.

### Как убедиться, что данные идут с бэкенда

- В терминале при обновлении `/dashboard` появляется `GET /api/v1/news ... 200 OK`.
- Если остановить бэкенд, дашборд покажет ошибку загрузки.
- Карточка про ставку ЦБ на **главной** (`Home.tsx`) вписана в код и видна всегда — проверяй на `/dashboard`.

## 3. API — краткая справка

Всё через proxy, на фронте только короткие адреса `/api/v1/...` (у тебя уже так).

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/api/v1/news` | лента с инсайтами, самые важные сверху |
| GET | `/api/v1/news/{id}` | одна новость или `404` |
| POST | `/api/v1/feedback` | лайк/дизлайк `{ news_id, insight_id?, is_like }` → `201` |
| POST | `/api/v1/analyze` | ИИ-агент: `{ title, content }` → инсайт |

Твои типы в `src/types/api.ts` полностью совпадают с бэкендом. Подробнее — `README_BACKEND.md` или Swagger.

**Помни про заглушки:** ML ещё не готов, поэтому новости и ответы агента пока ненастоящие (агент работает по ключевым словам), а лайки не сохраняются после перезагрузки. **Формат ответов финальный** — когда ML подключится, на фронте ничего менять не придётся.

## 4. Что нужно от тебя

### ❗ Главное: `package-lock.json` не совпадает с `package.json`

| Пакет | `package.json` | `package-lock.json` |
|---|---|---|
| react | ^18.2.0 | 19.3.1 |
| lucide-react | ^0.294.0 | 1.57.0 |

Из-за этого `npm ci` падает с ошибкой `ERESOLVE` у любого, кто клонирует репозиторий (ребята, жюри, сервер при деплое). Сейчас обходим через `npm install --legacy-peer-deps`.

Похоже, ты обновила пакеты у себя, а закоммитила только lock-файл. Как поправить:
1. `git status` — если `package.json` у тебя изменён, закоммить его **вместе** с `package-lock.json`.
2. Если не изменён — `npm install`, проверь, что всё запускается, закоммить оба файла.
3. Проверка: удали `node_modules`, выполни `npm ci` — должно пройти без ошибок.

- `src/types/client.ts` — копия `src/api/client.ts`, нигде не импортируется. Видимо, можно удалить.
