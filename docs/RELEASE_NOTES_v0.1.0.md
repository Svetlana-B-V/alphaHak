## 🧩 Компоненты UI-Kit

### Button
```tsx
<Button variant="primary" size="md">Нажми меня</Button>
```
- **Варианты:** `primary`, `secondary`, `outline`, `ghost`
- **Размеры:** `sm`, `md`, `lg`
- **Состояния:** hover, focus, disabled

### Badge
```tsx
<Badge variant="success">Успешно</Badge>
```
- **Варианты:** `default`, `success`, `warning`, `error`, `info`

### Card
```tsx
<Card hoverable padding="md">
  <CardHeader>
    <CardTitle>Заголовок</CardTitle>
    <CardDescription>Описание</CardDescription>
  </CardHeader>
  <CardContent>Содержимое</CardContent>
  <CardFooter>Подвал</CardFooter>
</Card>
```

## 🚀 Как запустить проект

### Для разработчиков

```bash
# 1. Клонировать репозиторий
git clone <URL_репозитория>
cd alphahak

# 2. Установить зависимости
npm install

# 3. Запустить dev-сервер
npm run dev

# 4. Открыть в браузере
http://localhost:5173
```

### Основные команды

| Команда | Описание |
|---------|----------|
| `npm run dev` | Запуск dev-сервера (http://localhost:5173) |
| `npm run build` | Production-сборка в папку `dist/` |
| `npm run typecheck` | Проверка типов TypeScript |
