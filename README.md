# **🔮 ИНСАЙТ // РАДАР (Yandex Executive Panel)**

**Инсайт-Радар** — это AI-панель для топ-менеджмента (C-level), которая превращает сырой информационный шум (новости, законопроекты, пресс-релизы) в четкие персонализированные рекомендации и оценивает их влияние на бизнес компании (на примере экосистемы Яндекса).

## **⚠️ Проблема: Информационный перегруз и упущенное время**

Каждый день происходят тысячи событий: меняется ключевая ставка ЦБ, выходят новые законы о персональных данных, меняются условия логистики.  
Руководителю приходится:

1. Тратить часы на чтение ленты и фильтрацию информационного шума.  
2. Самостоятельно анализировать: *"Как именно эта новость о задержке серверов за рубежом повлияет на наши дата-центры?"*  
3. Терять время на передачу задачи профильным отделам (CFO, Казначейство, Юристы).

## **💡 Решение: ИИ-Ассистент для принятия решений**

Мы создали систему, которая **читает новости за вас**.  
Платформа пропускает поток данных через ML-модель, отсеивает мусор (события с важностью от 1 до 4\) и выводит на дашборд только критические сигналы в удобном виде.  
**Как это работает:**

* **Оценка важности (1-10):** Мгновенное понимание приоритета события.  
* **Анализ влияния:** Четкий ответ, как событие отразится на компании (например, *"Меняется стоимость долга Яндекса с плавающей ставкой"*).  
* **Готовая рекомендация:** Что нужно сделать прямо сейчас (например, *"Казначею: оценить рефинансирование через кредитную линию"*).  
* **Live-Агент:** Возможность в 1 клик вставить текст любого внешнего документа и получить его ИИ-разбор.

## **🏗 Архитектура и Технический стек**

Проект разделен на 3 независимых микросервиса: **Frontend**, **Backend** и **ML-модуль**.

Plaintext  
 ┌────────────────┐      REST API      ┌────────────────┐      LLM / RAG     ┌────────────────┐  
 │  Frontend      │ ◄────────────────► │  Backend       │ ◄────────────────► │  ML Core       │  
 │  (React/Vite)  │     JSON (HTTP)    │  (FastAPI)     │                    │  (ChromaDB)    │  
 └────────────────┘                    └────────────────┘                    └────────────────┘

### **🎨 Frontend (UI/UX)**

Интерфейс разработан в корпоративной стилистике Young & Yandex с использованием абстрактной геометрии, стекломорфизма и многослойных компонентов. Инсайты организованы в виде «пчелиных сот» (Honeycomb grid) для быстрой визуальной оценки матрицы рисков.

* **Стек:** React 18, Vite 6, TypeScript 5\.  
* **Стилизация:** Tailwind CSS 4, CSS-переменные, кастомные шрифты (YS Text, YS Display).  
* **Анимации:** Framer Motion (живой параллакс-фон при скролле, интерактивные метабол-блоки, плавное появление).  
* **Роутинг:** React Router DOM v6.

### **⚙️ Backend (API & Data)**

Надежный и быстрый мост между пользовательским интерфейсом и ML-моделями.

* **Стек:** Python 3.11+, FastAPI.  
* **База данных:** SQLAlchemy (ORM), Alembic (миграции), SQLite (для локальной разработки) / PostgreSQL (для продакшена).  
* **Схемы данных:** Pydantic (строгая валидация входящих и исходящих JSON).  
* **Особенности:** Настроенный CORS, каскадное удаление данных, защита от дублирования новостей по URL.

### **🧠 Machine Learning (В разработке)**

Здесь будет находиться интеллектуальное ядро системы.

* **Подход:** Retrieval-Augmented Generation (RAG).  
* **Векторная БД:** ChromaDB для хранения семантического профиля компании и контекста.  
* **Пайплайн:** Парсинг сырого текста \-\> Векторизация \-\> Запрос к LLM с промптом профиля \-\> Выдача строгого JSON (Событие, Влияние, Рекомендация, Оценка).  
* **Статус:** Интеграция пайплайна с бэкендом (запланировано в v0.3.0).

## **🚀 Быстрый старт (Локальная разработка)**

Для запуска проекта на вашем компьютере выполните следующие шаги.

### **⚡ Быстрый запуск одной командой**

Если зависимости уже установлены (`pip install -r requirements.txt` и `npm install`):

```
.venv\Scripts\activate      # Mac/Linux: source .venv/bin/activate
python run.py
```

Скрипт применит миграции БД и запустит бэкенд и фронтенд вместе. Сайт: http://localhost:5173, остановить всё: `Ctrl+C`.

Ниже - запуск по шагам, если ставите проект первый раз.

### **Шаг 1: Запуск Бэкенда**

Убедитесь, что у вас установлен Python 3.11+.

Bash  
\# 1\. Все команды выполняются из корня репозитория (рядом с alembic.ini)

\# 2\. Создайте и активируйте виртуальное окружение  
python \-m venv .venv  
\# Для Windows: .venv\\Scripts\\activate  
\# Для Mac/Linux: source .venv/bin/activate

\# 3\. Установите зависимости  
pip install \-r requirements.txt

\# 4\. Скопируйте файл конфигурации  
cp .env.example .env

\# 5\. Примените миграции (создание БД)  
alembic upgrade head

\# 6\. Запустите сервер FastAPI  
uvicorn app.main:app \--reload

* Бэкенд будет доступен по адресу: [http\://127.0.0.1:8000](http://127.0.0.1:8000)  
* Интерактивная документация (Swagger API): [http\://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

### **Шаг 2: Запуск Фронтенда**

Убедитесь, что у вас установлен Node.js (v18+). Откройте новый терминал.

Bash  
\# 1\. Из корня репозитория (рядом с package.json)

\# 2\. Установите зависимости  
npm install

\# 3\. Запустите dev-сервер  
npm run dev

* Откройте браузер по адресу: http\://localhost:5173  
  *(Фронтенд автоматически проксирует все запросы /api/v1/\* на ваш запущенный бэкенд).*
